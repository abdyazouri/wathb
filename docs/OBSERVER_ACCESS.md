# حسابات المراقبين (لوحة المتابعة للقراءة فقط)

المراقب حساب **للقراءة فقط** يرى بيانات التجربة والنشاط في لوحة ويب على السيرفر:
`https://wathb-api2.onrender.com/observer/`

يصلح لشريك خارجي (مثل Tech for Palestine)، أو عضو في الفريق، ولاحقًا لجهة ممولة تتابع برنامجها.

## القواعد الثابتة

- **قراءة فقط، على السيرفر نفسه:** أي طلب من مراقب خارج `/observer/` (واجهة التطبيقات `/api/`، ولوحة Django) يُرفض بـ 403، وأي طلب كتابة داخل اللوحة يُرفض بـ 403 (ما عدا الدخول والخروج وتعيين كلمة المرور).
- **لا تطبيقات جوال:** المراقب لا يستطيع الدخول على تطبيق أندرويد أو آيفون. حقل الهاتف عنده قيمة داخلية ليست رقمًا، ودخول التطبيقات يرفض دور المراقب، وأي رمز JWT لمراقب يُرفض بـ 403.
- **لا تسجيل ذاتي:** فقط المشرف ينشئ حسابات المراقبين.
- **لا يظهر لأي مراقب أبدًا:** أرقام الهواتف، أرقام الهوية، كلمات المرور، بيانات المحافظ، نص سبب النزاع (يظهر التصنيف فقط). رقم عملية Jawwal Pay يظهر منه **آخر ٤ أرقام فقط**، وفي مستوى «بالأسماء» فقط.
- **السجل:** كل دخول، وكل محاولة دخول فاشلة، وكل صفحة يفتحها المراقب، وكل تصدير، يُكتب في سجل التدقيق الذي لا يُعدَّل ولا يُحذف (`AuditEvent`، الأفعال تبدأ بـ `observer_`).
- **الجلسة** تنتهي بعد ٤ ساعات، ويُطلب الدخول من جديد.
- **محاولات الدخول:** بعد ٥ محاولات فاشلة خلال ١٥ دقيقة لنفس البريد أو من نفس العنوان (IP) يُقفل الدخول ١٥ دقيقة.
- كل صفحات اللوحة عليها `noindex` فلا تظهر في محركات البحث.

## مستويات الرؤية

| المستوى | ماذا يرى | الصفحات المتاحة |
|---|---|---|
| `aggregate` (أرقام إجمالية) | أرقام ورسم أسبوعي فقط | النظرة العامة، تصدير CSV |
| `pseudonymised` (أسماء مستعارة) | الأرقام + سجل النشاط وجدول المنشآت، والعمال يظهرون «عامل #12» والمنشآت «منشأة #3» | الكل |
| `named` (بالأسماء) | كما سبق لكن بأسماء العمال والمنشآت وعنوان الوظيفة، وآخر ٤ أرقام من رقم العملية | الكل (لفريق داخلي موثوق) |

- الأرقام المستعارة **عشوائية**، تُعطى لكل عامل ومنشأة مرة واحدة وتُخزَّن (جدول `Pseudonym`)، ونفس الرقم يظهر لكل المراقبين. لا تُشتق من الأرقام الداخلية.
- في مستوى الأسماء المستعارة لا يظهر عنوان الوظيفة، لأنه نص حر قد يحمل اسم المنشأة.

## النطاق

لكل مراقب نطاق (`ObserverScope`): **كل المنشآت** أو **منشآت محددة**، مع تاريخ بداية ونهاية اختياريين. الفترة التي يطلبها المراقب في اللوحة تُقصّ دائمًا على حدود نطاقه.
لاحقًا، الجهة الممولة تأخذ حساب مراقب نطاقه مرتبط ببرنامجها، دون تغيير نموذج المراقب.

## الفترة

- **الافتراضي: «كل الفترة»** — من أول سجل (أول وظيفة نُشرت) حتى اليوم. حقلا التاريخ يبدآن فارغين.
- التواريخ **فلتر اختياري**: يختار المراقب «من» و/أو «إلى» ويضغط «عرض». رابط «مسح التواريخ» يرجع لكل الفترة.
- أزرار سريعة: «كل الفترة»، «فترة التجربة» (من `TRIAL_START_DATE` إلى `TRIAL_END_DATE` على Render، ولا يظهر إن لم يُضبطا)، «آخر ٤ أسابيع».
- الرسم الأسبوعي وملف CSV يتبعان نفس القاعدة: كل الفترة افتراضيًا، أو التواريخ المختارة.
- تواريخ نطاق المراقب (إن وُجدت) تحدّ ما يراه دائمًا، أيًّا كان اختياره.

## بيانات الاختبار

- المنشآت المعلَّمة `is_test` (حقل على ملف المنشأة)، وكل ما يرتبط بها من وظائف ومهام وأجور وإعلانات دفع ونزاعات، **لا تظهر في أي صفحة للمراقب ولا في التصدير**، حتى لو ذكرها نطاقه.
- المعلَّم حاليًا: المنشآت 1 و2 و3 (المنشآت التجريبية التي سبقت التجربة)، بالهجرة `accounts 0009`.

## التعريفات

- **عامل نشط:** عنده مهمة مقبولة أو جارية أو مكتملة يوم عملها داخل الفترة.
- **منشأة نشطة:** نشرت وظيفة في الفترة أو عندها مهمة كهذه.
- **دُفع يوم العمل نفسه:** أول إعلان دفع للأجر في نفس يوم العمل للمهمة (توقيت غزة).
- **أكّد العامل الاستلام:** العامل نفسه أكّد (ليس التأكيد التلقائي بعد ٢٤ ساعة).
- **الوسيط: ساعات من الإتمام حتى الدفع:** من تأكيد إتمام العمل حتى أول إعلان دفع.
- **منشآت نشرت في أسبوعين أو أكثر:** نشرت وظائف في أسبوعين مختلفين أو أكثر داخل الفترة.
- **التصدير (CSV):** صف لكل أسبوع وصف أخير للفترة كلها، أرقام مجمّعة فقط بلا أي سجل فردي.

## إدارة المراقبين عبر الـ API (للمشرف)

خطة Render المجانية بلا Shell، وحساب المشرف ليس من موظفي لوحة Django، لذلك الإدارة عبر نقاط API **للمشرف فقط** (`ADMIN`)، بنفس رمز الدخول الذي يستعمله المشرف في التطبيق. أي دور آخر، ومنه المراقب، يأخذ 403.

| الطلب | المسار | ماذا يفعل |
|---|---|---|
| `POST` | `/api/v1/admin/observers/` | إنشاء مراقب. الحقول: `name`، `organisation`، `email`، `level`، `language`، `expires_at`، واختياريًا `business_ids` (فارغ = كل المنشآت)، `start_date`، `end_date`. الرد فيه `set_password_link` **مرة واحدة فقط**. |
| `GET` | `/api/v1/admin/observers/` | قائمة المراقبين (بلا روابط). |
| `PATCH` | `/api/v1/admin/observers/<id>/` | تمديد (`expires_at`)، إيقاف أو تفعيل (`is_active`)، تغيير المستوى (`level`). |
| `POST` | `/api/v1/admin/observers/<id>/link/` | رابط جديد لكلمة المرور (٤٨ ساعة، مرة واحدة). |

كل إجراء يُكتب في سجل التدقيق (`observer_created`، `observer_updated` مع ما تغيّر، `observer_link_issued`)، والرابط نفسه لا يُخزَّن ولا يُكتب في السجل أبدًا.

## إنشاء مراقب

عبر الـ API (أعلاه)، أو من سطر الأوامر على السيرفر (Render ← Shell، غير متاح في الخطة المجانية) أو محليًا:

```
python manage.py create_observer --name "اسم الشخص" --org "Tech for Palestine" \
  --email partner@example.org --level aggregate --lang en --expires 2027-03-01
```

خيارات النطاق (اختيارية): `--businesses 3,7` (أرقام ملفات المنشآت) و`--from 2026-12-01` و`--to 2026-12-24`.

الأمر يطبع **رابطًا لمرة واحدة** لتعيين كلمة المرور، صالحًا **٤٨ ساعة**. لا يطبع أي كلمة مرور، والحساب لا يملك كلمة مرور حتى يستعمل المراقب الرابط.

أو من لوحة Django (`/django-admin/` ← Observer profiles ← Add): يظهر الرابط مرة واحدة في رسالة أعلى الصفحة بعد الحفظ.

## تمديد، تغيير، إيقاف

```
python manage.py update_observer --email partner@example.org --extend 2027-06-01
python manage.py update_observer --email partner@example.org --level pseudonymised --lang ar
python manage.py update_observer --email partner@example.org --deactivate
python manage.py update_observer --email partner@example.org --activate
python manage.py observer_link --email partner@example.org      # رابط جديد لكلمة المرور
```

في لوحة Django: إجراءات «Extend by 30 days» و«Deactivate» و«Activate» و«New set-password link».

- الإيقاف أو انتهاء تاريخ الصلاحية يُخرج المراقب من الجلسة فورًا مع الطلب التالي ويمنعه من الدخول.
- لتغيير النطاق: عدّل نطاقه في لوحة Django (Observer scopes).

## مشاركة رابط كلمة المرور بأمان

- أرسل الرابط **للشخص نفسه فقط**، في رسالة خاصة (بريد أو واتساب مباشر)، لا في مجموعة ولا في مستند مشترك.
- الرابط يعمل مرة واحدة ولمدة ٤٨ ساعة. إن انتهى أو شككت أنه وصل لغير صاحبه: أنشئ رابطًا جديدًا (`observer_link`)؛ الرابط القديم يبطل تلقائيًا بمجرد تعيين كلمة المرور.
- كلمة المرور ١٢ حرفًا على الأقل، ليست شائعة ولا أرقامًا فقط. لا يعرفها أحد غير المراقب، ولا تُطلب منه أبدًا.
- اطلب من المراقب الدخول من `https://wathb-api2.onrender.com/observer/login/` فقط.

## ملاحظات للنشر

- الهجرات (`accounts 0007` و`observers 0001`) تعمل تلقائيًا مع النشر (`build.sh`).
- المتغيّرات على Render: `TRIAL_START_DATE` و`TRIAL_END_DATE`، واختياريًا `OBSERVER_BASE_URL` (الافتراضي `https://wathb-api2.onrender.com`، وهو أول الرابط الذي يطبعه `create_observer`).
